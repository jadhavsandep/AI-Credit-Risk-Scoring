# AI Credit Risk Scoring

## Business Problem
Banks need to identify customers who are likely to repay loans and those who may default.

## Project Workflow
Dataset → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights

## Tools Used
- PostgreSQL
- SQL
- Power BI
- Python
- Jupyter Notebook

## Key Findings
- Total Customers: 1000
- Good Risk Customers: 700
- Bad Risk Customers: 300
- Average Credit Amount: 3271
- Most Common Loan Purpose: Car
